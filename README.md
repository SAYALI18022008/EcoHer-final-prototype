# EcoHer Demo

This package contains the complete EcoHer frontend prototype.

## Run it

Extract the ZIP and open `index.html` in a modern web browser. The app uses browser local storage for demo accounts, saved businesses, products, and requests. Photography and fonts load from remote URLs, so an internet connection is needed for those assets.

## Source

`index.html` contains the complete HTML, CSS, demo data, and JavaScript. No build step or package installation is required.
