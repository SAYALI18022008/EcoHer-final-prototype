# EcoHer

EcoHer is a local-first website for women-led sustainable businesses. Create an account, log in, save businesses, send mentorship and product requests, edit your profile, and track impact updates.

## Run the website

Install Node.js, then from this folder run:

```sh
npm install
npm run dev
```

Open the local address Vite prints, usually http://localhost:5173. Do not open index.html directly from a file path; use the local server.

## Accounts and saved data

Accounts are saved in the browser where you create them. Use the same browser and device to log in again. No Supabase project, API key, email confirmation, or service account quota is needed. This is a frontend demo: browser-local accounts are not shared across devices and are not suitable for sensitive or production use.
